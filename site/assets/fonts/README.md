# 文档站字体

在本目录放入以下原始字体，构建时会将字体嵌入站点。也可以通过 CMake 的 `SUNFLECK_DOC_FONT` 和 `SUNFLECK_DOC_MONO` 指定其他路径。

| 文件 | 用途 | 许可 |
| --- | --- | --- |
| NotoSansCJKsc-Regular.otf | 简体中文界面，来自 Noto CJK 的 Sans/OTF/SimplifiedChinese 目录 | [OFL-CJK](OFL-CJK.txt) |
| NotoSansMono.ttf | 代码等宽字体，来自 Google Fonts 的 Noto Sans Mono | [OFL-Mono](OFL-Mono.txt) |

原始字体来自 [Noto CJK](https://github.com/notofonts/noto-cjk) 和 [Google Fonts](https://github.com/google/fonts)。
